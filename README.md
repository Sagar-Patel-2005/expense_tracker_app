# 💰 Expense Tracker App

A Flutter-based Expense Tracker application for managing daily expenses.

## ✨ Features

- Add and delete transactions
- Manage title, amount, category, and date
- SQLite local database
- Pie Chart expense visualization
- Form validation

## 🛠️ Technologies Used

- Flutter
- Dart
- SQLite
- FL Chart
